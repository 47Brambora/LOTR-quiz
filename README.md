# Lord of the Rings Quiz

**Fan-made Tolkien quiz / Fanouškovský Tolkienovský kvíz**

Projekt vytvořený jako osobní dárek, který postupně rozšiřuji o nové funkce.  
A personal gift project that I continue to expand with new features.

### 🇨🇿 / 🇸🇰

## 🛠️ Instalace / Installation

### 🇨🇿 / 🇸🇰

Aby projekt správně fungoval, je potřeba dodržet několik kroků:

#### **1) Umístění projektu (DŮLEŽITÉ)**

Projekt **musí být uložen ve složce, jejíž cesta neobsahuje háčky, čárky ani jiné speciální znaky**.  
Například:

✔️ `C:\Games\LOTR-quiz`  
❌ `C:\Hry\Kvízy\LOTR-kvíz`  
❌ `C:\Uživatelé\Štěpán\Dokumenty\LOTR`

Některé nástroje a servery neumí pracovat s diakritikou v cestách, což může způsobit chyby při spuštění.

#### **2) Stažení a instalace Mongoose**

Projekt používá **Mongoose** jako jednoduchý lokální webový server.

1. Stáhněte si `mongoose.exe` z oficiální stránky: https://mongoose.ws/binary/
2. Umístěte `mongoose.exe` do hlavní složky projektu (vedle `index.html`)
3. Spusťte projekt pomocí `start.bat`

#### **3) Spuštění projektu**

Pro splnění výše uvedených kroků:

- spusťte `start.bat`
- server se automaticky spustí
- otevře se vám váš defaultní prohlížeč na adrese: **http://localhost:8000** pokud ne spuste prohlížeč a zadejte adresu manuálně

### 🇬🇧

To ensure the project works correctly, please follow these steps:

#### **1) Project location (IMPORTANT)**

The project **must be placed in a folder whose path contains no accented characters or special symbols**.  
For example:

✔️ `C:\Games\LOTR-quiz`  
❌ `C:\Hry\Kvízy\LOTR-kvíz`  
❌ `C:\Users\Štěpán\Documents\LOTR`

Some tools and servers cannot operate correctly when the path contains diacritics.

#### **2) Download and install Mongoose server**

This project uses **Mongoose** as lightweight local web server.

1. Download `mongoose.exe` from official website: https://mongoose.ws/binary
2. Place `mongose.exe` into the main project folder (next to `index.html`)
3. Launch the project using `start.bat`

#### **3) Running the project**

After completing the steps above:

- run `start.bat`
- the server will start automatically
- and your default browser automatically open at **http://localhost:8000** if not open it manualy
