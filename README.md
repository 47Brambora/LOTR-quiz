## 🛠️ Installation

To ensure the project works correctly, please follow these steps:

### **1) Project location (IMPORTANT)**

The project **must be placed in a folder whose path contains no accented characters or special symbols**.  
For example:

✔️ `C:\Games\LOTR-quiz`  
❌ `C:\Hry\Kvízy\LOTR-kvíz`  
❌ `C:\Users\Štěpán\Documents\LOTR`

Some tools and servers cannot operate correctly when the path contains diacritics.

### **2) Download and install Mongoose server**

This project uses **Mongoose** as lightweight local web server.

1. Download `mongoose.exe` from official website: https://mongoose.ws/binary
2. Place `mongose.exe` into the main project folder (next to `index.html`)
3. Launch the project using `start.bat`

### **3) Running the project**

After completing the steps above:

- run `start.bat`
- the server will start automatically
- and your default browser automatically open at **http://localhost:8000** if not open it manualy
