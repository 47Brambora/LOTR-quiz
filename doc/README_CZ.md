# Lord of the Rings Quiz

**Fanouškovský Tolkienovský kvíz**  
Projekt vytvořený jako osobní dárek, který postupně rozšiřuji o nové funkce.

---

## Popis projektu

Tento projekt je fanouškovský kvíz inspirovaný světem J. R. R. Tolkiena.  
Vznikl jako dárek pro mou přítelkyni, která miluje Tolkienův svět.  
Plánuji ho dále rozvíjet, přidávat nové otázky, funkce a vizuální prvky.
